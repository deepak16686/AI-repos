# Pipeline Failure Triage (GitLab, agentic DevOps)

An AI-assisted agent that turns a failed GitLab CI pipeline into an evidence-backed root-cause note on the merge request. The agent reads widely (job logs, MR diffs, history, Loki/Prometheus/Jaeger, SonarQube, Trivy, Nexus, past fixes) and writes narrowly (one MR note). Humans make every consequential decision.

**Status:** design complete, implementation not started. This folder contains documentation only. The code will live in a separate GitLab project (`devops-ai/pipeline-triage`, created in task T0.2).

## Key decisions at a glance

* **GitLab** is the source of events, MRs and issues; the agent acts as a Reporter-role bot user.
* **One config file selects the LLM.** `llm-providers.yaml` has one boolean per provider: Ollama (default, local, no cost), OpenAI, Claude, or any OpenAI-compatible endpoint. Switching providers needs no code change.
* **Everything is containerized** and joins the existing `ai-platform-net` Docker network; no `docker.sock` is mounted into any new container.
* **Autonomy ceiling is a comment.** Creating an issue or teaching the agent a fix needs an explicit, recorded approval from a Developer or higher.
* **Shadow mode first**, then comment mode, so quality is measured before engineers see any output.
* The full decision register (D1 to D17) and the open questions with defaults are in document 01, section 16.

## Rebuilding the documents

The PDFs are generated from the Markdown with pandoc and headless Chromium; the diagrams are generated by small Python scripts that embed brand icons from [Simple Icons](https://simpleicons.org) (CC0).

```bash
# PDFs (needs pandoc and Chromium; set CHROME to override discovery)
python3 docs/tools/build_pdfs.py

# Diagrams (needs the simple-icons npm package unpacked, e.g. `npm pack simple-icons@13.21.0`)
export SIMPLE_ICONS_DIR=/path/to/package
python3 docs/tools/diagrams/build_extra.py   ../ai-setup-diagrams
python3 docs/tools/diagrams/build_diagram.py ../ai-setup-diagrams/pipeline-failure-triage-architecture.svg
```

Run the diagram commands from `pipeline-failure-triage/`. Logos are trademarks of their respective owners.
